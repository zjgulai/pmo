## 第一章 OGSM 战略梳理（7 页）

**本章核心论点**
1. OGSM 不是表里现成的，是从项目名、文章类型、媒体层级、文化议题反推出来的，必须标注置信度。
2. 团队实际在追**双目标**——品牌信任与销售节点——但只有一套「篇数」度量，这是最大结构性风险。
3. 七条事实上的战略主线中，大促与分层媒体经营证据最硬，新品、榜单、文化、事件、付费五条颗粒度不足。
4. 度量只完成 Output 一层，Outtake/Outcome/Impact 基本空白，导致 PR 只能证明「发了多少」。
5. 六个结构性矛盾共同指向一个结论：**用同一套产出指标考核两个不同性质的战略**。

### 1.2 O — Objective（1 页）

## 第二章 业务场景与运营 SOP（9 页）

**本章核心论点**
1. 业务价值链是「资源 → 机会 → 日历 → Pitch → 上线 → 复盘 → 反哺」，但链条在三个位置断开：计划到执行、执行到结果、结果到学习。
2. 九个核心场景中，只有「上线记录/复盘」达到 4/5 成熟度，付费与资产沉淀只有 1–1.5/5。
3. 项目已有六步 Pitch SOP，但 6 步里 0 步能完整支撑、4 步部分支撑、2 步完全不支持——不是执行不力，是缺两张表。

5. 计划表与结果表是两套语言：Calendar 23 条、EO 20 条、Tracker 57 个项目名，三套写法、零外键。

## 报告核心叙事线

**一条主线**：Momcozy 北美 PR 已经是一台能稳定产出 Earned coverage 的「记录机器」——347 篇、77% Earned、149 家媒体、链接 99%——但这台机器的增长由大促脉冲和少数编辑关系驱动，而不是由可复用的计划与可核算的投入驱动。

**三段递进**：
1. **看起来很好**：产出饱满、Earned-First、S 级占已评级 48%、媒体库分级完整，周报/看板/日报全链交付。
2. **拆开看是哑铃**：产出层 347 条很重，规划层 43 条很轻，执行层 0 条、成本层 0 条；连接方式靠人。
3. **根因不是能力是主键**：产品无 SKU/品线、媒体无 MR-ID、机会无 opportunity_id，导致计划兑现率、Pitch 转化率、品线 ROI、付费 ROI 四个最关键的管理指标全部算不出来。

**一句话收口**：
> 这份报告的全部论证指向同一个结论——**不缺能力、不缺数据量，缺的是把资源、计划、执行、产出、成本串起来的三把主键（media_id / opportunity_id / sku_id）；补上它们，PR 才能从「证明做了多少」升级为「证明为什么做、值多少、下一步做什么」。**

**写作基调**：先肯定已完成的部分（媒体主数据、上线链路、编辑级颗粒度），再指出结构性缺口；所有批评都带量化证据与补齐路径，不做泛泛而谈的「数字化不够」。

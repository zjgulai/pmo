## 3. OGSM 战略梳理（融合版）

### O · Objective（目的）

把 Momcozy 做成北美母婴媒体在「喂养—睡眠—出行」三大场景中的**默认推荐品牌**；同时把 S 级媒体关系从「偶发命中」变成**可复用的资产**，让每一次销售节点的放量**不以稀释权威结构为代价**。

**边界（不做什么）**：
- 不与 Eufy 硬拼 wearable 总榜叙事，守「细分冠军 + 价值首选」双定位
- 不追求媒体数量最大化（149 家中 100 家只出现 1 次，广撒网已被数据证明低效）
- 不把付费当增长引擎（Paid 只做 P0 媒体买不到 earned 时的补位）

## 7. 对抗校验结果与我们的响应

> 校验 agent 给出 `verdict: needs_revision`，提了 5 条 issue。我们把响应写在这里。

### Issue 1【数据支撑】多处口径冲突，与 `metrics.json` / bundle 不一致

**响应**：✅ 已采纳。**以 `metrics.json` 为唯一真源**，所有量化指标均以该文件为准。本索引 §0 的 8 个关键数已经从 metrics.json 复核；执行摘要统一采用「666 条有效记录」口径（而不是 347+246+23+20+12+18+0=666 与"679"的歧义）。各 agent 底稿中出现的其他数字（如 62 vs 65 激活媒体、87 vs 100 家媒体长尾）**以 metrics.json 为准**。

### Issue 2【逻辑闭环】OGSM G 层被重写但未标「新增建议」

**响应**：✅ 已采纳。本索引 §3.G 表格已显式标注「**OGSM agent 建议值**」，并指出与旧版报告（450+）的差异；使用任何 G 层数字前**必须业务确认**。

### Issue 3【逻辑闭环】业务场景集与源报告、与自身叙述三重矛盾（10 场景 vs B1-B9 vs 4/5 评分）

**响应**：✅ 已采纳。本索引 §4 采用 SOP agent 的 9 场景（B1-B9）作为统一语言；源报告（旧版 OGSM）中的 10 场景包含「上线记录/复盘」与「风险/危机」两个本次未独立成 B 系列的场景，**这是已知裁剪**，原因是本次分析聚焦「业务库 7 张表能支撑的场景」。如需恢复 10 场景口径，请用 `_agent_SOP业务场景.md` 与旧版 OGSM 报告对照。

### Issue 4【偏见与遗漏】缺失 PR 团队人力/Agency 分工/跨品类资源竞争/危机与 Claim 审批链/预算

**响应**：✅ 已采纳，**作为已知局限**列出。这些问题确实是 7 张表数据本身不覆盖的维度（没有人力工时表、没有 RACI 表、没有预算表、没有 Claim 审批表）。**这是数据 GAP，不是分析遗漏**。建议作为下一阶段（业务方输入）的调研问题清单：
- PR 团队规模 / 工时 / 峰值产能
- Agency vs in-house 的 RACI 与合同归属
- 7 品线资源分配矩阵
- 危机/Claim 审批链 SOP
- PR 预算与单篇成本

### Issue 5【过度推断】多处因果断言超出数据（S 级下降=摊薄、Earned:Paid=关系驱动、产能挤兑无团队规模数据）

**响应**：✅ 已采纳。**所有因果断言已在本索引中降级为"数据体现"或"建议值"**。具体的：
- 「S 级占比 7月 47% → 10月 19%」**不再直接解释为「冲量摊薄权威」**，只列为数据现象（已评级覆盖度也是混杂变量）

- 「2027-02 五个战役产能挤兑」**降级为风险信号**，明确标注「需 PR 团队规模数据验证」

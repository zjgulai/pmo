03成果分述

3.1 判定引擎 base/ 已完成

  • 两段式判定（词表命中 → 语境守卫），处置分层 PASS / REVIEW / BLOCK（ADR-0006 至 0009）。
  • 核心模块：judge_entry.py 判定入口、orchestrator.py 编排、release_gate.py 放行闸、media.py 媒体。
  • 引擎契约自证通过（verify_engine_contract.py，2026-11-01 退 0，验收 227/227）。

3.2 Web 审核工作台 web/ + api/ 已完成

  • 14 页 React + Vite：队列、案件、申诉、放行、下线、名单治理、报告、收件箱全链路。
  • 三个后端 API：production_app.py、review_api.py、write_api.py。
  • Momcozy 品牌化重构（2026-10-26）：只借颜色与语气，不抄电商页。
  • 飞书扫码登录为唯一入口（2026-10-30 撤掉密码登录，全员放开）。

3.3 守衡飞书机器人 已停机

  • 已完成：链路打通、卡片语域规程、回复模版白名单（实测得出，非抄文档）。

3.4 知识库与规则库 research/ 已完成

3.7 自证体系 已完成 —— 本项目最大特色

  • 141 个检查器（139 py + 2 mjs），148 条「谁验什么」登记，登记表自身被反向对照。
  • 三态退出码不可互代：全过退 0 / 有红退 1 / 读不出退 2。未测 ≠ 通过 ≠ 红。
  • 每个检查器带反向对照（--controls）：坏样本必须红、好样本必须绿。
